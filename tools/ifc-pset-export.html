What this tool does

This tool parses an IFC file entirely in your browser using web-ifc. It maps all available IFC Classes to their associated Property Sets (Psets). You can select a class, select a specific Pset attached to elements of that class, export the Pset, and download the modified topological graph as a new IFC file.

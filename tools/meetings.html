What this tool does

This allows you to create and manage meeting minutes and threads. Keep track of every open issue, while assigning them to your team in one place. You can export it as an Excel file and bring it back to continue editing opened issues in following meetings.

This tool uses an Universal Excel files so you can load your contact back and in other webapps from this website.

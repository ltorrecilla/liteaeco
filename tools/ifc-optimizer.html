IFC Optimizer

Graph Compression & Deduplication

What this tool does

This tool optimizes single IFC files by deduplicating redundant topological and geometric resources, trimming excessive float precision, and utilizing Web-IFC for deep graph compression (tree-shaking) to significantly reduce the overall file size. If needed, it can also remove information about colors within the model or even completly remove property sets, quantities, and attribute values, leaving only the geometry.

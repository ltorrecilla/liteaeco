IFC Inject Properties

What this tool does

This tool parses an IFC file entirely in your browser using web-ifc. You can add entirely new properties to one or multiple IFC classes simultaneously, load a spreadsheet to overwrite existing values, and download the updated topological graph as a new IFC file.

IFC Application Changer

IFC Compatibility for Autodesk

What this tool does

Some Autodesk Apps such as Forma (Previous ACC) won't handle IFC files generated by 3rd party tools properlyExamples of these tools include Tricad, Istram and LuxArtX, among others. This issue happens specially on Model Coordination, where an IFC file is not recognized and throws an error as "Can't clash model".
Upload IFC files and replace IFCAPPLICATION(...) with a target Revit version and set the FILE_NAME header timestamp to the current local time.

IFCAPPLICATION (#1,'22.0.11','TRICAD-MS IFC Exporter','TriIfcExport') (#1,'2026','Autodesk Revit 2026 (ENU)','Revit')
FILE_NAME timestamp YYYY-MM-DDTHH:MM:SS±HH:MM
